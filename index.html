Install in 3 steps

Before you start, you need Claude Code on your computer and a Claude sign-in. The app's first screen checks this and walks you through it.

1
Open the downloadDouble-click the .dmg file, then drag Accela Chat into Applications.
2
Open it the first timeRight-click Accela Chat in Applications and choose Open, then Open again. If it is still blocked: System Settings, Privacy & Security, Open Anyway.
3
Connect your toolsSign in to Claude Code if asked, then open Connections to add Outlook, Salesforce, Gong and Pursuit.
This build is for Macs with Apple silicon (M1, M2, M3, M4). Check Apple menu, About This Mac. It needs macOS 12 or newer and a Claude Code sign-in.
Why the security prompt? This is a preview signed with a personal certificate, not an Apple-notarized release, so your Mac asks once before opening it.
